# Absolute Cinema– Ticket 4.1: Műsor nézet



## Indítás

```bash
npm install
npm run dev
```

## Funkciók

- dátum szerinti műsor;
- filmcím és műfaj szerinti keresés;
- műfajszűrés;
- rendezés kezdési idő, ABC és játékidő szerint;
- vetítési időpont és terem kiválasztása;
- kiválasztott vetítés összegzése;
- kedvencek kapcsolása.
